# Team photos

Drop player photos here and every visitor sees them, on every device.

**Filename must be the player's name, lowercased, spaces and punctuation
replaced with hyphens, `.jpg`:**

```
jackson-lewis.jpg
asher-steele.jpg
manuel-cruz-jr.jpg
```

Coach > Manage > Team Photos has a **Download Photo Pack** button that names
them correctly for you. Save them into this folder, commit, push.

Aim for a portrait crop around 600px on the long edge. Anything bigger just
costs parents mobile data.
